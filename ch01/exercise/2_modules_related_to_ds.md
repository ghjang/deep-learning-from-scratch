# 2. 데이터 과학 관련 모듈

## 2.1 데이터 분석 라이브러리 개요

a. __numpy__

* '넘파이'라고 읽는다.
* '수치 계산'용 라이브러리이다.
* '선형 메모리 배치'를 보장하는 '배열'을 제공한다. 내부적으로 'C/C++'로 구현되어 있다. 결과적으로 'C/C++'에서 이용 가능한 '선형 메모리 배치'의 '배열'을 파이썬에서 사용할 수 있게 해준다.
* 파이썬의 '리스트'를 넘파이 '배열'로 변환하면 '수치 계산'이 빨라진다.
* '넘파이'는 '행렬'이나 '다차원 배열'을 쉽게 처리할 수 있게 해준다.

b. __pandas__

* '판다스'라고 읽는다.
* '데이터 처리와 분석'을 위한 라이브러리이다.
* '판다스'는 '시리즈'나 '데이터프레임'이라는 자료형을 제공한다.

c. __scipy__

* '싸이파이'라고 읽는다.
* '과학 기술 계산'용 라이브러리이다.
* '싸이파이'는 선형 대수, 수학 함수, 신호 처리, 특수한 수학 함수와 통계 분포 등을 포함한 다양한 기능을 제공한다.

d. __matplotlib__

* '맷플롯립'이라고 읽는다.
* '그래프'를 그려주는 라이브러리이다.
* '맷플롯립'을 이용하면 데이터를 그래프로 그려 시각적으로 파악하기 쉽다.

## 2.2 머신러닝 라이브러리 개요

a. __scikit-learn__

* '싸이킷런'이라고 읽는다.
* '싸이킷런'은 '머신러닝'에서 사용할 수 있는 다양한 알고리즘과 편리한 기능을 제공한다.

## 2.3 딥러닝 라이브러리 개요

a. __tensorflow__

* '텐서플로'라고 읽는다.
* '딥러닝'을 위해 만들어졌으며, '다양한 딥러닝 기능'을 제공한다. 현재 업계에서 가장 널리 사용되는 주요 딥러닝 프레임워크 중 하나이다.

b. __keras__

* '케라스'라고 읽는다.
* '텐서플로'나 '씨아노' 등의 딥러닝 라이브러리를 간단하게 사용할 수 있게 해준다. 이제 TensorFlow의 공식 고수준 API로 통합되었다.

c. __pytorch__

* '파이토치'라고 읽는다.
* '페이스북'이 만들었으며, '텐서 조작'이나 '미분' 계산 등을 수행할 수 있다. 현재 업계에서 가장 널리 사용되는 주요 딥러닝 프레임워크 중 하나이다.

d. __chainer__

* '체이너'라고 읽는다.
* '행렬 계산'이나 '딥러닝'을 쉽게 구현할 수 있게 해준다.

e. __theano__

* '테아노'라고 읽는다.
* '텐서 조작'이나 '미분' 계산 등을 수행할 수 있다. 현재 개발이 중단된 상태이다.
